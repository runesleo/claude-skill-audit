# Skill ON/OFF 实效验收卡（手填）

从最近真实做过的任务中挑 1–3 个，不选演示型玩具题。相同输入、相同评价标准分别跑一次，先定标准再看结果。

| 字段 | 任务 A | 任务 B | 任务 C |
| --- | --- | --- | --- |
| 原始任务链接/编号（私有） |  |  |  |
| 应触发的 Skill |  |  |  |
| 没触发的原因（如适用） |  |  |  |
| 完成质量标准（事先写） |  |  |  |
| 不用 Skill：质量 / 时间 / 成本 / 返工 |  |  |  |
| 使用 Skill：质量 / 时间 / 成本 / 返工 |  |  |  |
| 有什么证据支持差异 |  |  |  |
| 结论：保留 / 修复触发 / 继续观察 |  |  |  |

记录原则：

- 没实际跑过的填「待验证」，不要编数字。
- 如果两个结果使用了不同模型、上下文或工具，标记「对照不严格」，避免因果误判。
- 效果不只看速度；质量更差、返工变多的自动化可能是负收益。
- 安全、故障应急、合规类 Skill 单独评估保留价值，不能以 30 天内是否调用决定删除。
